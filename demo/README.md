# Lanternfall 3D demo — exported build

This folder holds the playable 3D demo as a self-contained HTML file,
exported from the Muse web artifact `lanternfall-3d`.

- `index.html` — open it in Chrome to play. First-person Haven, WASD +
  mouse look, third-person toggle (CAM / V), NPCs Mira, Bram, Wren,
  Fenn, Tomas, quests (wolves, ember herbs, glowcaps, river-reeds,
  star-moss), combat, loot, XP and levels.
- This export is the current artifact build as of Nov 1, 2026 (evening):
  it includes the PS2 visual pass (detailed models, mottled ground,
  richer lantern lighting) and the living-world animation pass (NPC idle
  life, wolf run-cycle, lantern flicker, grass sway).
- Note: the public link still serves the last published version (v2)
  until the v3 publish. This export is ahead of the public link.
- Sync note: the artifact is still the source of truth for the demo.
  This GitHub copy is updated by manual export after artifact builds,
  so it can lag the artifact between exports. If you review it, say
  which export date you reviewed so we can tell what you saw.
- The Python sim in the rest of this repo is separate: it is the
  world/economy/quest brain, not this playable client.
